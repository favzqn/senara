Aksesibilitas

Komitmen kami untuk membuat Senara bisa diakses oleh semua orang.

🎯 Komitmen Kami

Kami percaya bahwa setiap orang berhak mengakses cerita dan pengalaman belajar yang bermakna. Senara terus berupaya meningkatkan aksesibilitas platform agar inklusif untuk semua pengguna, termasuk mereka dengan disabilitas.

Berikut adalah fitur aksesibilitas yang sudah tersedia dan yang sedang kami kembangkan.

👁️ Aksesibilitas Visual

🔤

Ukuran Font yang Cukup

Teks di seluruh website menggunakan ukuran minimum 16px untuk memastikan keterbacaan. Pada perangkat mobile, ukuran font disesuaikan agar tetap nyaman dibaca.

✓ Tersedia
🎨

Kontras Warna

Kami menggunakan kombinasi warna dengan kontras yang cukup antara teks dan background. Warna utama (amber/coklat) dipilih untuk keterbacaan yang baik.

✓ Tersedia
🔍

Zoom Browser

Website mendukung zoom browser hingga 200% tanpa kehilangan fungsionalitas atau konten. Layout akan menyesuaikan secara responsif.

✓ Tersedia
🌙

Mode Gelap

Mode tampilan gelap untuk mengurangi kelelahan mata saat membaca dalam kondisi cahaya rendah.

📋 Direncanakan

⌨️ Navigasi & Interaksi

🖱️

Navigasi Keyboard

Semua elemen interaktif (link, tombol, menu) dapat diakses menggunakan keyboard. Gunakan Tab untuk berpindah antar elemen dan Enter untuk mengaktifkan.

✓ Tersedia
🎯

Focus Indicator

Elemen yang sedang difokuskan ditandai dengan outline yang jelas, memudahkan pengguna keyboard untuk mengetahui posisi mereka.

✓ Tersedia
📱

Touch Target

Tombol dan link memiliki area sentuh minimum 44x44 pixel untuk memudahkan pengguna dengan keterbatasan motorik.

✓ Tersedia
⏸️

Kontrol Animasi

Animasi di website minimal dan tidak mengganggu. Tidak ada animasi yang berkedip cepat yang bisa memicu kejang.

✓ Tersedia

🔊 Screen Reader & Teknologi Bantu

📝

Struktur Heading

Halaman menggunakan hierarki heading (H1, H2, H3) yang terstruktur dengan baik untuk memudahkan navigasi dengan screen reader.

✓ Tersedia
🏷️

ARIA Labels

Elemen interaktif dilengkapi dengan label ARIA untuk memberikan konteks kepada pengguna screen reader.

⚡ Sebagian
🖼️

Alt Text untuk Gambar

Gambar penting dilengkapi dengan teks alternatif yang mendeskripsikan konten gambar.

⚡ Sebagian
🗣️

Kompatibilitas Screen Reader

Website diuji dengan screen reader populer seperti NVDA dan VoiceOver untuk memastikan kompatibilitas.

📋 Direncanakan

🎮 Aksesibilitas Visual Novel

Fitur aksesibilitas khusus untuk pengalaman membaca cerita interaktif:

⚡

Kecepatan Teks

Pengaturan kecepatan tampilan teks yang bisa disesuaikan, termasuk opsi untuk menampilkan teks secara instan.

✓ Tersedia
🔊

Kontrol Audio

Volume musik dan efek suara bisa diatur secara terpisah atau dimatikan sepenuhnya.

✓ Tersedia
💾

Save & Load

Simpan progress kapan saja dan lanjutkan nanti. Tidak perlu menyelesaikan cerita dalam satu sesi.

✓ Tersedia
📖

Log Dialog

Akses riwayat dialog untuk membaca ulang teks yang sudah lewat.

✓ Tersedia

Tips Menggunakan Senara

  • Gunakan Ctrl/Cmd + untuk memperbesar tampilan jika teks terlalu kecil
  • Tekan Tab untuk berpindah antar tombol dan link
  • Di visual novel, klik atau tekan Enter/Space untuk melanjutkan dialog
  • Gunakan menu Settings di visual novel untuk mengatur kecepatan teks dan volume

Bantu Kami Meningkatkan Aksesibilitas

Jika kamu mengalami kesulitan mengakses Senara atau punya saran untuk meningkatkan aksesibilitas, kami sangat ingin mendengarnya.
