# Senara — Overview

**Live:** https://senara.id/
**Version:** 1.0.4
**Tagline:** "Belajar Lewat Cerita" (Learn Through Stories)

## What It Is

Nonprofit Indonesian educational platform that teaches life topics (mental health, financial literacy, inclusivity, etc.) through interactive visual novel stories. No login, no personal data collection, no cookies.

## Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | Vanilla HTML/CSS/JS (no framework, no build tools) |
| CSS | Tailwind CDN + 6 custom CSS files |
| VN Engine | Monogatari (bundled in `monogatari/`) |
| Analytics | Umami (privacy-focused, no cookies) |
| Fonts | Inter (UI) + Nunito (headings) via Google Fonts |
| PWA | service-worker.js + manifest.json |
| Hosting | Netlify / Cloudflare Pages / Vercel / Wasmer |

## Design System

**Style:** Claymorphism — soft 3D, chunky borders, double shadows, playful
**Colors:** Indigo (#4F46E5) primary, Orange (#F97316) CTA, Deep (#1E1B4B) text
**Fonts:** Crimson Pro (headings) / Atkinson Hyperlegible (body)
**Generated by:** [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) design system generator

## Key Characteristics

- **No backend** — fully client-side static site
- **No build system** — files served as-is, cache-busted via `?v=` query strings
- **No module system** — global scope, `Object.freeze()` on config/constants
- **i18n** — Indonesian + English via `getText(key, fallback)` and `data-i18n` attributes
- **Offline support** — service worker with cache-first strategy
- **Analytics** — Umami via `data-umami-event` HTML attributes

## Content Status

2 published stories, 7 planned categories, many more stories in pipeline.
