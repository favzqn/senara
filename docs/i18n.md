# Internationalization (i18n)

## Overview

Two languages: Indonesian (`id`) and English (`en`). Custom IIFE module, no framework.
Source code defaults are English. Indonesian translations in `id.js`, English in `en.js`.

## Files

| File | Purpose |
|------|---------|
| `js/i18n-simple.js` | I18n module (IIFE exposing `I18n` global) |
| `js/locales.js` | Locale loader — sync `document.write()` based on `localStorage` preference |
| `js/locales/id.js` | Indonesian translations (~1200 lines) |
| `js/locales/en.js` | English translations (~1200 lines) |
| `js/shared-utils.js` | Contains `getText(key, fallback)` helper |

## How It Works

1. `locales.js` reads `localStorage.senara_language` (default: `id`)
2. Uses synchronous `document.write()` to inject the correct locale `<script>`
3. Locale file sets `I18n.register('id', { ... })` with all translations
4. On `DOMContentLoaded`, elements with `data-i18n="key"` attribute are auto-translated
5. JS-side: use `getText(key, fallback)` for user-facing strings

## Patterns

### HTML: `data-i18n` attribute
```html
<h1 data-i18n="team.title">Senara Team</h1>
```
English is the default text. `data-i18n` replaces it with the translation from the locale file.

### JS: `getText(key, fallback)` function
```js
// In shared-utils.js — available globally
function getText(key, fallback) {
  if (typeof I18n !== 'undefined' && I18n.isReady && I18n.isReady()) {
    const translated = I18n.t(key);
    return translated !== key ? translated : fallback;
  }
  return fallback;
}

// Usage
const label = getText('story.play', 'Play');
```

### JS: `t(key, fallback)` in story-page.js
```js
// Similar to getText but defined in story-page.js
function t(key, fallback = '') {
  if (typeof I18n !== 'undefined' && I18n.t) {
    const result = I18n.t(key);
    return result !== key ? result : fallback;
  }
  return fallback;
}
```

### HTML: `data-i18n-html` for rich content
```html
<p data-i18n-html="team.whyP2">
  We believe there's a better way: <strong>through stories</strong>.
</p>
```

## Translation Key Structure

```js
{
  "nav.home": "Home",
  "nav.collection": "Stories",
  "categories.mind-emotions": "Mind & Emotions",
  "story.play": "Play",
  "team.title": "Senara Team",
  "tv.watchNow": "Watch Now",
  "common.loading": "Loading...",
  // ~1200 keys per locale
}
```

## Key Sections

| Section | Keys | Used by |
|---------|------|---------|
| `nav.*` | Navigation labels | navbar.js |
| `footer.*` | Footer labels | footer.js |
| `home.*` | Homepage content | index.html (data-i18n) |
| `story.*` | Story card labels | shared-utils.js, home-page.js |
| `stories.{id}.*` | Story titles/descriptions | shared-utils.js, home-page.js |
| `categories.{id}` | Category titles | categories.js |
| `categories.{id}-desc` | Category descriptions | categories.js |
| `collection.*` | Collection page labels | collection-page.js |
| `storyPage.*` | Story detail page | story-page.js |
| `team.*` | Team page content | team.html (data-i18n) |
| `tv.*` | Video library labels | video-library.js |
| `common.*` | Shared strings | shared-utils.js, performance-utils.js |
| `whyVN.*` | Why VN comparison | home-page.js |
| `testimonials.*` | Testimonial quotes | home-page.js |

## Interpolation

Uses `{{param}}` syntax:
```js
I18n.t('story.chapters', { count: 5 })  // "5 Chapter"
```

## Language Toggle

Pill-style toggle in navbar with ID/EN flags. On switch:
1. Updates `localStorage.senara_language`
2. Reloads page (full page reload, not hot swap)

## Adding a New Language

1. Create `js/locales/{lang}.js`
2. Copy structure from `en.js`, translate all keys
3. Register: `I18n.register('{lang}', { ... })`
4. Add locale option to the language toggle in `navbar.js`
5. Update `locales.js` to handle the new locale

## Adding New Translation Keys

1. Add the key to both `en.js` and `id.js`
2. In HTML: add `data-i18n="key"` attribute (default text should be English)
3. In JS: use `getText('key', 'English fallback')` at render time
4. Do NOT call `getText()` at module load time — i18n may not be ready yet

## Known Issues

- `document.write()` for locale loading is a blocking anti-pattern — works but blocks parsing
- No hot-swap — language change requires full page reload
- Meta tags (`<meta description>`, OG tags) are not localized — they use hardcoded HTML
- Story scripts (`monogatari/stories/`) are Indonesian-only — not part of the i18n system
